Preparing your CSV

  • Use the template headings. Required columns: {{ required_columns|join:", " }}.
  • Each row needs a name, positive price, category, size, and condition. Blank stock defaults to 1; zero means unavailable.
  • Use an existing active username in seller, or leave it blank to use the default seller.
  • Prices can be plain numbers such as 75000 or rupiah amounts such as 75.000. Quote values containing a comma, for example "75.000,50".
  • Optional photo links must use HTTPS. Omit optional columns or leave their values blank.
  • Import up to 500 items in a UTF-8, comma-separated CSV of up to 2 MB.
  • Each import creates new listings. Importing the same file again as a new upload creates additional listings.
